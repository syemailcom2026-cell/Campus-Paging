# 校园传呼 Campus Pager

轻量级校园语音呼叫系统，基于 MQTT 实时通信，支持发送端（手机/电脑）和接收端（大屏/电脑）双向消息推送与语音播报。

## 功能特性

### 📡 实时通信
- 基于 MQTT 协议的即时消息推送，低延迟
- 房间号隔离，支持多班级/多区域同时使用
- 在线状态实时检测，接收端离线自动提醒
- 房间号冲突检测，防止多人同时占用同一房间

### 📢 播报能力
- 浏览器原生语音合成（TTS），无需额外安装
- 可调语速、音调、音量、播报字号
- 支持重复播放遍数和间隔设置
- 接收端支持小窗通知 / 强制大屏两种弹窗模式
- 大屏播报结束自动退回后台

### 🎨 个性化外观
- 8 种预设 UI 配色方案，支持自定义主色
- 深色/浅色模式自动跟随系统
- 支持自定义背景图片，可调背景透明度、卡片透明度
- 自动从背景图提取主色调适配 UI
- 底部胶囊形悬浮 Tab 栏，大圆角卡片设计
- 宽屏自动两列布局，手机端单列手风琴设置

### 📋 呼叫管理
- 多选学生批量呼叫
- 常用目的地自定义管理（教务处、办公室、医务室等）
- 呼叫记录自动保存，支持一键清空
- 常用播报模板快速选择

## 下载

- **Windows 独立版**：直接下载 `CampusPager-独立版.exe` 运行，无需安装
- **Android 版**：下载 `CampusPager-v1.6.1.apk` 安装到手机
- **网页版**：直接打开 HTML 文件即可使用，推荐 Chrome/Edge 浏览器

## 技术栈

- 纯单文件 HTML/CSS/JavaScript，无需后端
- MQTT.js 实时通信
- Web Speech API 语音播报
- localStorage 本地保存用户设置
